# 📚 **SOOT Common Library Documentation**

**SOOT** (GOAL Object-Oriented Scripting) - стандартная библиотека для OpenGOAL/Jack. Написана на диалекте Scheme, совместимом с SOOT.

## 📋 **Базовые макросы**

### **Определение макросов и функций**

| Макрос      | Описание                 | Пример                                       |
|-------------|--------------------------|----------------------------------------------|
| `defsmacro` | Определение SOOT-макроса | `(defsmacro unless (clause &rest body) ...)` |
| `desfun`    | Определение SOOT-функции | `(desfun factorial (x) ...)`                 |
| `defgmacro` | Определение LOAM-макроса | `(defgmacro defmacro ...)`                   |

**Примеры:**

```scheme
;; Определение макроса
(defsmacro when (clause &rest body)
  `(if ,clause (begin ,@body) #f))

;; Определение функции
(desfun factorial (x)
  (if (= x 1) 1 (* x (factorial (- x 1)))))
```

## 🔄 **Управляющие конструкции**

### **Условные операторы**

| Макрос   | Аргументы                        | Описание                         |
|----------|----------------------------------|----------------------------------|
| `if`     | `condition true-expr false-expr` | Условный оператор                |
| `when`   | `condition &rest body`           | Выполнить если true              |
| `unless` | `condition &rest body`           | Выполнить если false             |
| `not`    | `x`                              | Логическое НЕ                    |
| `aif`    | `condition true false`           | Анафорический if (доступно `it`) |

**Примеры:**

```scheme
(if (> x 0) 
    (print "positive") 
    (print "non-positive"))

(when (file-exists? "data.txt")
  (load-file "data.txt")
  (process-data))

(aif (find-user id)
     (print "Found user:" it)
     (print "User not found"))
```

### **Циклы**

| Макрос    | Аргументы                      | Описание         |
|-----------|--------------------------------|------------------|
| `dotimes` | `(var count &optional result)` | Цикл с счетчиком |
| `dolist`  | `(var list &optional result)`  | Цикл по списку   |
| `while`   | `condition &rest body`         | Цикл while       |

**Примеры:**

```scheme
(dotimes (i 10)
  (print "Iteration:" i))

(dolist (item items)
  (process-item item))

(while (not (null? queue))
  (process (car queue))
  (pop! queue))
```

## 📊 **Операции со списками**

### **Аксессоры списков**

| Макрос   | Описание              | Эквивалент      |
|----------|-----------------------|-----------------|
| `caar`   | `(car (car x))`       | первый первого  |
| `cadr`   | `(car (cdr x))`       | первый второго  |
| `cdar`   | `(cdr (car x))`       | второй первого  |
| `cddr`   | `(cdr (cdr x))`       | второго второго |
| `caddr`  | `(car (cdr (cdr x)))` | первый третьего |
| `first`  | `(car x)`             | первый элемент  |
| `second` | `(cadr x)`            | второй элемент  |
| `third`  | `(caddr x)`           | третий элемент  |
| `rest`   | `(cdr x)`             | хвост списка    |

### **Модификация списков**

| Функция/Макрос  | Аргументы    | Описание              |
|-----------------|--------------|-----------------------|
| `push!`         | `list value` | Добавить в начало     |
| `pop!`          | `list`       | Удалить первый        |
| `cons!`         | `list obj`   | Алиас для `push!`     |
| `append!`       | `list obj`   | Добавить в конец      |
| `append!!`      | `list obj`   | То же с присваиванием |
| `delete-last!`  | `list`       | Удалить последний     |
| `delete-last!!` | `list`       | То же с присваиванием |

**Примеры:**

```scheme
(define stack '())
(push! stack 1)     ; stack = (1)
(push! stack 2)     ; stack = (2 1)
(pop! stack)        ; stack = (1)

(define queue '(a b))
(append! queue 'c)  ; queue = (a b c)
```

### **Функции обработки списков**

| Функция         | Аргументы               | Описание                             |
|-----------------|-------------------------|--------------------------------------|
| `count`         | `list`                  | Длина списка                         |
| `apply`         | `func list`             | Применить функцию к списку           |
| `apply2`        | `func1 func2 lst1 lst2` | Применить две функции к двум спискам |
| `filter`        | `predicate list`        | Фильтрация списка                    |
| `member`        | `element list`          | Проверить наличие элемента           |
| `assoc`         | `key alist`             | Найти по ключу в alist               |
| `assocn`        | `x a`                   | Найти индекс элемента                |
| `nth`           | `n list`                | n-ный элемент                        |
| `list`          | `&rest items`           | Создать список                       |
| `reverse`       | `list`                  | Обратить список                      |
| `repeated-list` | `obj count`             | Список из N повторений               |
| `length`        | `list`                  | Длина списка                         |

**Примеры:**

```scheme
(count '(a b c))             ; → 3
(apply (lambda (x) (* x 2)) '(1 2 3)) ; → (2 4 6)
(filter (lambda (x) (> x 0)) '(-1 2 -3 4)) ; → (2 4)
(member 'b '(a b c))         ; → (b c)
(assoc 'name '((name . "John") (age . 25))) ; → (name . "John")
```

## 💡 **Примеры использования**

### **Создание утилитных функций:**

```scheme
;; Фильтрация четных чисел
(desfun filter-even (lst)
  (filter (lambda (x) (= (mod x 2) 0)) lst))

;; Поиск по ключу с дефолтом
(desfun safe-assoc (key alist default)
  (let ((result (assoc key alist)))
    (if result (cdr result) default)))
```

### **Обработка списков:**

```scheme
;; Преобразование списка пар в хэш-таблицу
(desfun alist->hash (alist)
  (let ((ht (make-hash-table)))
    (dolist (pair alist)
      (hash-table-set! ht (car pair) (cdr pair)))
    ht))
```

### **Работа с пользователями:**

```scheme
;; Загрузка пользовательской конфигурации
(defun load-user-config ()
  (when (user? "admin")
    (load-file "admin-config.sot"))
  (when (user? "tester")
    (load-file "test-config.sot")))
```

## ⚠️ **Важные особенности**

1. **SOOT vs GOAL**: Библиотека работает в двух контекстах - SOOT (интерпретатор) и GOAL (компилятор)
2. **Совместимость**: Макросы определены для работы в обоих окружениях
3. **Производительность**: Некоторые функции (как `let`, `let*`) переписаны на C++ для скорости
4. **Игровая специфика**: Содержит функции для работы с игровыми данными Jak & Daxter
